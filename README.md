# Single-file web app

The deployable web app is a single self-contained HTML file:

- `/home/runner/work/august-hackathon/august-hackathon/index.html`

It includes inline CSS and inline JavaScript and does not require a separate frontend/backend runtime.

## Netlify deployment

`netlify.toml` is configured to publish the repository root so Netlify serves `index.html` as the entry point.

## Local preview

Open `index.html` directly in a browser, or run any static file server from the repository root.
